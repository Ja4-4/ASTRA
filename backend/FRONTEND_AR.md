# ربط الفرونت إند بالباك اند (ASTRA)

الفرونت (`frontend/`، React + Vite) صار يقرأ ويكتب على الباك اند (Rust). الباك اند يخدم الفرونت المبني من `static/`، فكل شي على عنوان واحد.

## التشغيل

```
cd frontend && npm ci && npm run build      # يبني dist/
cp -r dist/. ../backend/static/             # الباك اند يقدّم static/
cd ../backend
cargo run --release -- seed --ui            # قاعدة بيانات ببيانات الديمو نفسها اللي تظهر على الشاشة
cargo run --release -- serve                # http://127.0.0.1:8000
```

للتطوير: `npm run dev` في `frontend/` (يمرّر `/api` و`/eye` إلى `127.0.0.1:8000` تلقائياً). لو الباك اند على عنوان ثاني: `VITE_API_URL=http://host:port`.

Atlas (الصوت/النص) يحتاج خادم النموذج، انظر `ATLAS_AR.md`. بدونه كل شي ثاني يشتغل.

## وش يصير عند الفتح

1. الفرونت يسأل `/api/health`. لو الباك اند يرد: يقرأ الرائد والقياسات والتنبيهات والأحداث والروتينات وحالة التطبيق. الشارة فوق تقول **Live · اسم الرائد**.
2. لو ما رد: يشتغل **وضع الديمو** (بيانات داخل المتصفح فقط) والشارة تقول ذلك بوضوح مع زر Retry. ما يخفي الوضع أبداً.

## من وين تجي البيانات

| الشي | مصدره | يُحفظ وين |
|---|---|---|
| القياسات (9 مؤشرات) | الباك اند `/api/measurements` | الباك اند |
| النقاط والشارات وخطوات التنبيه والتفضيلات | حالة التطبيق | الباك اند `PUT /api/astronauts/{id}/state` (مؤجَّل 0.8 ثانية، ويُرسَل عند إغلاق الصفحة) |
| أحداث التنبيه (act now) | قواعد الفرونت | تُنسخ إلى `/api/events` وتُغلق هناك لما تنغلق في التطبيق |
| تنبيهات القواعد (review) | قواعد الباك اند | تظهر في صفحة Alerts تحت "Flagged by the server rules" مع Acknowledge |
| الروتين | `/api/routines` | يظهر في صفحة Routine؛ إنهاء جلسة تمرين يكمل روتين التمرين في الباك اند |
| البيئة (ISS) والاستيراد والمصادر والعين | الباك اند | صفحة Cabin (`/cabin`) |
| Atlas | `/api/atlas/*` | قراءة تنفذ فوراً، كتابة تنتظر موافقتك، أوامر الواجهة (تنقل، مظهر، رائد) ينفذها الفرونت |

مسح متصفح المستخدم ما يضيّع شي: كل شي يرجع من الباك اند.

## ملاحظات مهمة

- **الساعة:** الديمو يمشي على ساعة مُحاكاة (2026-11-13 08:45 UTC) عشان القصة تكون ثابتة. الفرونت يرسل وقته مع كل قياس، وAtlas يستلم نفس الوقت (`at` في `/api/atlas/command`) فالأرقام اللي يسجلها تظهر على الشاشة. تأكيد الروتين يستخدم ساعة السيرفر الحقيقية.
- **مجموعتا قواعد:** قواعد الفرونت (Good / A bit off / Act now) وقواعد الباك اند (review/info) مستقلتين، والعتبات في الاثنين مؤقتة وغير معتمدة من الشريك البحثي. ممكن يختلفون وهذا متوقع.
- **الرواد الثانيون:** كل رائد له قياساته وحالته. لكن خط الأساس الشخصي في الفرونت (`data/demo/profile.ts`) ثابت لكل الرواد.
- **اللغة:** الواجهة إنجليزية فقط. أمر Atlas "غيّر اللغة" يعرض تنبيه فقط.
- **صفحة Progress (Crew):** أسماء الطاقم فيها بيانات ديمو، مو من الباك اند.
- **Reset:** `Shift+R` (أو `POST /api/demo/reset`) يرجع القصة للبداية: يمسح ما كتبه التطبيق وAtlas والأحداث وحالة التطبيق ويحمّل التاريخ من جديد. ما يلمس ملفات مستوردة أو رواد ثانيين.

## الاختبار

- `cargo test`: اختبارات الباك اند (تشمل الحالة والإغلاق والمسارات والساعة وreset).
- `e2e/`: اختبار متصفح حقيقي (Playwright + Chrome) يمشي على كل الصفحات والميزات. `e2e/stub_model.py` نموذج **وهمي للاختبار فقط** يرد على جمل ثابتة، عشان نختبر الأنبوب كامل بدون النموذج الحقيقي.

```
python3 e2e/stub_model.py 18234 &
ASTRA_AI_PROVIDER=openai ASTRA_AI_URL=http://127.0.0.1:18234/v1 ASTRA_AI_MODEL=ai cargo run -- serve   # ثم:
ASTRA_E2E_URL=http://127.0.0.1:8000 ASTRA_E2E_DATA_RAW=data/raw ASTRA_E2E_OUT=. python3 e2e/e2e.py
```
(يحتاج `pip install playwright` وChrome؛ `CHROME_PATH` اختياري. شغّله على قاعدة تجريبية، لأنه يسجل بيانات ويعمل reset.)

## واجهات جديدة في الباك اند

`GET|PUT /api/astronauts/{id}/state` · `POST /api/events/{id}/close` · `POST /api/demo/reset` ·
`POST /api/events` يقبل `opened_at` · `POST /api/atlas/command` يقبل `at` · مؤشران جديدان (`exercise_min`, `rad_dose`) ·
أي مسار `/api/...` غير موجود يرد JSON 404 · أي مسار ثاني يفتح الفرونت (روابط عميقة مثل `/log`).
أوقات القياسات تُخزَّن بصيغة موحّدة (UTC بالثواني) مهما أرسل العميل.

## الواجهة الجديدة + أطلس الصوتي (دمج ayman-api)

- الواجهة المبنية الجديدة (React + Vite + Three.js) تُخدَّم من `backend/static/`. لإعادة البناء: `cd frontend && npm run build` ثم انسخ `dist/.` إلى `backend/static/` (اترك مجلد `static/dev`).
- **نداء "Atlas" / "أطلس"**: عندما يكون أطلس مغلقاً يستمع المتصفح للاسم (Web Speech API). عند سماعه يفتح شريط الصوت ويشغّل المايك تلقائياً ويكمل الجلسة نفسها للسؤال: «Atlas, how is my heart rate». زر "Say Atlas" يوقف/يشغّل الاستماع، والاختيار يُحفظ في المتصفح.
  - تنبيه خصوصية: في Chrome يُرسل الصوت إلى خدمة Google للتعرف على الكلام. أطلس نفسه لا يسجل ولا يحفظ صوتاً؛ يقرأ فقط مستوى الصوت لرسم الموجات.
  - لا يعمل بدون مايك أو بدون HTTPS/localhost، ولا يعمل في Firefox (لا يدعم SpeechRecognition): يتحول تلقائياً إلى الكتابة.
- **شريط الصوت**: نقاط عند الصمت وأعمدة عند الكلام (مثل ChatGPT)، ↑ لإرسال السؤال الآن، ■ للإيقاف، × للإغلاق، EN/AR لتبديل لغة الاستماع.
- **التأكيد بالصوت**: أي كتابة (تسجيل قياس، إضافة رائد، تأكيد تنبيه) يقترحها النموذج تنتظر "نعم/لا" (نطقاً أو بالأزرار) قبل أن تُحفظ. الصيغة: `/api/atlas/command` ثم `/api/atlas/confirm`.
- أكواد المؤشرات بين الواجهة والسيرفر: `exercise_minutes` (الواجهة تقرأ أيضاً `exercise_min` من `exercise.rs`) و`radiation_dose_cumulative`. المحاكاة (`demo follow-up`) تبقى في الواجهة ولا تُحفظ كقياسات حقيقية.
- حالة التطبيق (النقاط، الشارات، خطوات التنبيه) تُحفظ في السيرفر `/api/astronauts/{id}/state` وتعود بعد مسح تخزين المتصفح. `Shift+R` يعيد ضبط السيرفر والواجهة، و`Shift+D` يقدّم ساعة العرض.
- اختبار المتصفح الشامل: `backend/e2e/e2e.py` (80 فحصاً، يستخدم نموذجاً وهمياً `stub_model.py` ومحرك كلام وهمياً لاختبار نداء الاسم).
